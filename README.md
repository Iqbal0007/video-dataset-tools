# Video Dataset Tools

Local Windows utilities for computer-vision dataset preparation.

## Apps

- Video Convert — converts video files between common formats.
- Video to Images — extracts numbered JPG or PNG frames from a video into organized folders.

## Uses

- Object detection datasets
- Image classification datasets
- Video analysis
- Annotation workflows
- General computer-vision experiments

## Requirements

- Windows
- FFmpeg installed and available on PATH
